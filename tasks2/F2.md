Add a playback direction to the VX Drum Sequencer engine in `src/modules/VXDrumSequencer/VXDrumSequencerEngine.hpp`, which is Rack-free and compiled with only its own directory on the include path. Only the engine is in scope: do not change the module or the widget, and keep every existing signature working.

Specification:

- Add `enum Direction { FORWARD = 0, BACKWARD = 1, PENDULUM = 2 };` in namespace `vx_drum_sequencer`.
- `Playhead` gains a public `int direction` that defaults to `FORWARD`, and `int advance(int length)` honours it. `length` is clamped to 1..STEPS as today.
  - FORWARD: unchanged.
  - BACKWARD: the next step is the previous one; from step 1 (position 0) it wraps to the last step (`length - 1`). A position at or beyond `length` (the length shrank) goes to the last step.
  - PENDULUM: steps run forward to the last step, then backward to step 1, then forward again, and the end steps are not repeated. For a length of 4 starting at position 0, successive calls return 1, 2, 3, 2, 1, 0, 1, 2, 3, 2, ... For a length of 1 every call returns 0. A position at or beyond `length` goes to the last step and the next move is backward.
  - A hand-off (position -1) lands on step 1 (position 0) in every direction, and in PENDULUM the next move is forward.
- `Playhead::reset()` keeps putting step 1 current and, in PENDULUM, makes the next move forward. `Playhead::rewind()` is unchanged.
- `Sequencer` gains `void setDirection(int d)`, which stores `d` on its playhead and treats any value outside 0..2 as `FORWARD`, and `int direction() const` which returns it. Everything else about `Sequencer` is unchanged.
