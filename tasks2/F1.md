Add a per-step chance to the Euclid sequencing engine in `src/modules/Euclid/EuclidEngine.hpp`, which is Rack-free and compiled standalone by `tests/euclid`. Only the engine is in scope: do not change the module or the widget.

Specification:

- Add `struct Rng` in namespace `euclid`: a xorshift32 with `uint32_t state` that starts at `0x9E3779B9`, `void seed(uint32_t s)` which stores `s`, or `0x9E3779B9` when `s` is 0, `uint32_t next()` which applies `x ^= x << 13; x ^= x >> 17; x ^= x << 5;` and stores and returns the result, and `int percent()` which returns `next() % 100`.
- `Sequencer` gains a public member `Rng rng;`.
- Add an overload `Out process(bool reset_edge, bool clock_edge, int window_samples, int hits, int steps, int rot, int chance)`. The existing six-argument `process` must keep working and behave exactly as `chance` 100.
- `chance` is a percentage clamped to 0..100. It applies when the playhead lands on a step through a clock edge or a reset. If that step is a rest, nothing is rolled. If it is a hit: with chance 100 the step plays and nothing is rolled; with chance 0 the step does not play and nothing is rolled; otherwise exactly one call to `rng.percent()` is made and the step plays when the result is below `chance`. No other code path may consume the generator.
- A step that plays reports `struck` on the landing sample and `gate` high for as long as the playhead stays on it. A step that lost its roll behaves as a rest for the whole stay: `struck` false on the landing sample and `gate` low on every sample until the playhead moves. Idle samples never re-roll. `gate_gap` keeps its meaning (it depends on whether `gate` was high on the previous sample). The pattern table itself is never changed.
- `load()` does not roll; after load, step 1's gate follows the pattern as it does today.

Update the comments at the top of the engine to describe the chance rule, and add tests to `tests/euclid` covering: the six-argument form unchanged, chance 0, determinism with a seeded generator, and a lost roll holding the gate low until the next clock. All existing tests must keep passing.
