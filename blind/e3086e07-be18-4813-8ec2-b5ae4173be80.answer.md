- **Env lookup:** `Option.resolve_envvar_value` in `src/click/core.py:3748`. It first calls `Parameter.resolve_envvar_value` (`core.py:2868`), which checks the explicit `envvar` (a string, or a list where the first non-empty value wins). Empty values count as unset.
- **Auto prefix fallback:** if no explicit envvar is found, and `allow_from_autoenv` is true, `ctx.auto_envvar_prefix` is set, and the option has a `name`, it reads `os.environ[f"{ctx.auto_envvar_prefix}_{self.name.upper()}"]` (`core.py:3763-3764`).
- **Prefix construction:** `Context.__init__` (`core.py:503-521`) builds the prefix. An explicit prefix is upper-cased. Otherwise it's inherited as `f"{parent.auto_envvar_prefix}_{self.info_name.upper()}"`. Either way, `-` becomes `_`. For example, prefix `MYAPP`, subcommand `sub-cmd` and option `name` give `MYAPP_SUB_CMD_NAME`.
- **Raw value to parameter value:** `Option.value_from_envvar` (`core.py:3772`) converts the string. Non-bool flags become `flag_value` or `False`. Values for `nargs != 1` or `multiple` are split with `type.split_envvar_value`. The base version is `Parameter.value_from_envvar` (`core.py:2913`).
- **Resolution order:** `Parameter.consume_value` (`core.py:2680-2726`) tries each source only while the value is still `UNSET`:
  1. command line (the parser's `opts`) → `COMMANDLINE`
  2. environment (`value_from_envvar`) → `ENVIRONMENT`
  3. default map (`ctx.lookup_default`) → `DEFAULT_MAP`
  4. `get_default` → `DEFAULT`
- **Prompt:** `Option.consume_value` (`core.py:3820`) runs after that. If prompting is enabled, it prompts when the value is still unset or came from the default map or default (`source >= DEFAULT_MAP`). An environment value therefore stops the prompt.
