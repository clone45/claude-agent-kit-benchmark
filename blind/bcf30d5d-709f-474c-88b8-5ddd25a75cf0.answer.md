The decision happens in a single place: `echo` calls `should_strip_ansi(file, resolve_color_default(color))`. It takes two inputs: the target stream and a tri-state color flag (True, False or None).

1. **Call site:** `src/click/utils.py`, `echo` (~line 330). The check only applies to `str` output, since bytes go to the binary stream untouched (~lines 320–326). If it returns True, the text goes through `strip_ansi`, then `file.write`. `file` is either the stream passed in or, if none was given, the default stdout/stderr (stderr when `err=True`, ~lines 288–291).
2. **Color flag:** `src/click/globals.py`, `resolve_color_default` (lines 54–67). An explicit `color=` argument to `echo` wins. Otherwise it uses the current `Context.color`, or `None` if there is no context.
3. **Context color:** `src/click/core.py`, `Context.__init__` (lines 523–527). It uses the `color` argument passed to the context, or inherits `parent.color` when that is `None`.
4. **The rule:** `src/click/_compat.py`, `should_strip_ansi` (lines 502–513):
   - If color is True, keep the codes. If color is False, strip them.
   - If color is None and the stream has a `color` attribute (the pager's `_PagerWriter`), don't strip here, because the pager strips on its own.
   - Otherwise, strip unless the stream is a TTY or is Jupyter kernel output. (If the stream is `None`, it checks `sys.stdin` instead, but `echo` never passes `None`.)
5. **Helpers in `_compat.py`:** `isatty` (540–544) calls `stream.isatty()` and treats any exception as False. `_is_jupyter_kernel_output` (495–499) unwraps `_FixupStream`/`_NonClosingTextIOWrapper` and checks whether the stream's class module starts with `ipykernel.`. `strip_ansi` (491–492) removes matches of `_ansi_re` (line 19).

In short: an explicit `color` (from `echo` or the context) decides it. Otherwise colors are kept only for TTYs, Jupyter output and the pager, and stripped everywhere else, such as files, pipes and `StringIO`.
