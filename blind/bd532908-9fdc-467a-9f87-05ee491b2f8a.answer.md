The width is decided in `HelpFormatter.__init__` (`src/click/formatting.py:127-142`), and its inputs come from the `Context`:

- **Where it's decided:** `HelpFormatter.__init__(indent_increment=2, width=None, max_width=None)` stores the result in `self.width`. `write_usage`, `write_text` (which calls `wrap_text`) and `write_dl` all wrap to that value, minus the current indent.
- **Default:** if `max_width` is None it becomes 80 (line 135). After subtracting 2, the widest you get by default is 78. The class docstring (lines 118-119) says "clamped to a maximum of 78". On its own, `wrap_text` defaults to `width=78` (line 33).
- **Terminal size and minimum:** only when `width` is None, it computes `max(min(shutil.get_terminal_size().columns, max_width) - 2, 50)` (line 141). That takes the terminal columns, caps them at `max_width`, subtracts 2, and never goes below 50.
- **Test override:** the module global `FORCED_WIDTH` (formatting.py:11) is checked first (line 139). `CliRunner.isolation` sets it to 80 (`src/click/testing.py:438-439`) and restores it afterwards (line 593).
- **Context override:** `Context.make_formatter` (`src/click/core.py:664-676`) calls `self.formatter_class(width=self.terminal_width, max_width=self.max_content_width)`.
  - `terminal_width` and `max_content_width` are `Context.__init__` parameters. If you don't pass them, they're inherited from the parent context (core.py:438-449; documented at 265-275).
  - A non-None `terminal_width` is used exactly as given. It skips the terminal check, the -2, the 80 cap and the 50 floor.
  - `max_content_width` only changes the cap in the automatic calculation.
- **Command override:** pass `context_settings={"terminal_width": ..., "max_content_width": ...}` to a `Command` (core.py:995, 1086-1090). `Command.make_context` hands these to the `Context` (line 1386).
- **Custom formatter:** set `Context.formatter_class` (core.py:340) to your own `HelpFormatter` subclass, or override `make_formatter`. `Command.get_help` (line 1268) gets its formatter through `ctx.make_formatter()`.
