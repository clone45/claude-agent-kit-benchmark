When you press over a note, the editor checks a fixed chain of tests in order. The first one that matches decides whether the drag resizes the right edge, resizes the left edge, or moves the note.

1. **Entry:** `onButton` (`src/modules/PianoRoll/PianoRollEditorWidget.hpp:1624`) passes a left-button press to `beginDrag` (~1890). `beginDrag` calls `zoneAt` (1387) and, for `ZONE_GRID`, hands off to `beginGridDrag` (2031).
2. **Order inside `beginGridDrag`:**
   - A: Shift toggles whether the note is selected (no drag).
   - B: `selectionBounds` (1458). If two or more notes are selected and the press is inside their bounding box, the whole group moves. Edges aren't tested here, so a note in a group can't be resized.
   - C: `edgeGrabAt` (1422). A hit sets `DRAG_RESIZE`, and `drag_left_edge = grab.left_edge` records which edge (2076–2091).
   - D: `noteIndexAt` (1406). A hit on the note body selects only that note and calls `beginMove`.
   - E/F: empty space either clears the selection or paints a new note.
3. **Cursor preview:** `onHover`'s `ZONE_GRID` case (1590–1601) runs the same box → edge → body → empty checks, so the cursor shows what a press would do.
4. **Grab zone (`edgeGrabAt`, 1422–1452):** it only looks at notes on the active track in the pitch row from `pitchAtY`, newest note first. It converts the note's start and end to pixels with `xOfStep` (`x0`, `x1`). It tests distance in pixels, so the right edge (`note.end()`) can be grabbed even though `noteIndexAt`'s half-open span doesn't count the end step as inside the note.
5. **Zone size (line 1439):** `zone = min(EDGE_GRAB_W, max(1, (x1-x0)/3))`, with `EDGE_GRAB_W = 4px` (`PianoRollGeometry.hpp:127`). Wide notes get ±4 px. Narrower notes get a third of their width, never less than 1 px, so the edge zones can't cover the whole note and it can still be moved.
6. **Right edge first (1441):** if `|x - x1| <= zone`, it returns a right-edge resize right away. The left edge is only checked if that fails.
7. **Left edge (1445):** it also needs `(x1-x0) > EDGE_GRAB_MIN_NOTE_W`, which is `4 * 2.5 = 10px` (`PianoRollGeometry.hpp:128`). A note 10 px wide or narrower has no left grab zone at all. The comment says this keeps a left-edge grab from being confused with the nearby right edge. On a short note, a press near the left side falls through to `noteIndexAt` and moves the note instead.
