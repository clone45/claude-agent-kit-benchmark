All overrides are in `src/modules/VXDrums/VXDrumVoices.hpp`. Each model's `setShape` override is listed by line.

**1. Recomputes coefficients (calls `updateCoeffs()`):**
- Without a clamp: `Clap::setShape`, line 488.
- With a clamp to 0–1 first: `SnareSweep` 1247, `SnareGate` 1341, `Clap909` 1454, `ClapLoFi` 1656, `ClapGate` 1756.

**2. Only stores the value (`shape = v;`):**
- `Ping808` 346, `Snare909` 417, `SineKick` 653, `KickFm` 732, `Snare808` 922, `SnareLayered` 1009, `SnareRing` 1089.

**3. Clamps without recomputing (`shape = clampd(v, 0.0, 1.0);`):**
- `Hat` 562, `Snare606` 1168, `ClapTrap` 1551.

**Two models that do something different:**
- `KickDist::setShape` (826–830) stores `shape` and then works out one extra value itself, `fold = fastMax(0.0, (shape - 0.6) / 0.4)`. It has no clamp and doesn't call `updateCoeffs()`.
- `SampleModel::setShape` (1945) doesn't set `shape` at all. It writes `start = clamp01(v)`, so SHAPE controls the sample start point. It doesn't call `updateCoeff()`.

All of these are reached from `Voices::setShape` (2149–2153) and from line 2217. Both scale the knob's 0–1 position to the model's range with `knobNatural` (line 204) before calling the override.
