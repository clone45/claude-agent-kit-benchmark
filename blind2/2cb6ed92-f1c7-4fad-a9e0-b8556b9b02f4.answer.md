There are 20 voice models. All overrides are the `setShape` method in `src/modules/VXDrums/VXDrumVoices.hpp`; the pure-virtual base is `Model::setShape` at line 299.

**Recompute coefficients (store, then call `updateCoeffs()`)**
- Clap (488) stores the value as it arrives.
- SnareSweep (1247), SnareGate (1341), Clap909 (1454), ClapLoFi (1656) and ClapGate (1756) clamp it to 0..1 with `clampd` first.

**Only store (`shape = v;`)**
- Ping808 (346), Snare909 (417), SineKick (653), KickFm (732), Snare808 (922), SnareLayered (1009), SnareRing (1089).

**Clamp to 0..1 without recomputing**
- Hat (562), Snare606 (1168), ClapTrap (1551).

**Different from all three**
- **KickDist** (826–830) stores the value raw, then directly sets one derived field, `fold = fastMax(0, (shape − 0.6) / 0.4)`. It doesn't call `updateCoeffs()`, which in this model runs only from `setDecay` (824) and the sample-rate setup (822).
- **SampleModel** (1945) never writes a `shape` field. It reuses SHAPE as the sample start position: `start = clamp01(v)`, where `clamp01` (line 202) wraps `clampd(x, 0, 1)`.

**Where SHAPE comes from:** `Voices::setShape(int column, double v)` (2149–2153), and the loop at 2217, convert the knob value with `knobNatural(modelSpec(...).shape, v)` and call the active model's override.

I sorted these by reading each override line, plus the full KickDist method. I didn't check whether any store-only model also reads `shape` into cached state elsewhere, such as in `strike`.
