All 18 models in `src/modules/VXDrums/VXDrumVoices.hpp` override `setShape`, because `Model::setShape` is pure virtual (line 299). `Voices::setShape` (2149-2153) and line 2217 pass in a value already scaled by `knobNatural` (204).

**1. Recomputes coefficients (calls `updateCoeffs()`)** — 6 models:
- `Clap::setShape` at 488 stores the value and recomputes without clamping. It is the only member of this group with no clamp.
- These five clamp to [0,1] with `clampd` and then recompute: `SnareSweep` 1247, `SnareGate` 1341, `Clap909` 1454, `ClapLoFi` 1656, `ClapGate` 1756.

**2. Only stores the value (`shape = v`)** — 7 models: `Ping808` 346, `Snare909` 417, `SineKick` 653, `KickFm` 732, `Snare808` 922, `SnareLayered` 1009, `SnareRing` 1089.

**3. Clamps to [0,1] without recomputing** — 3 models: `Hat` 562, `Snare606` 1168, `ClapTrap` 1551.

**Different from all three:**
- `KickDist::setShape` (826-830) stores the value without clamping and also derives one field inline, `fold = fastMax(0, (shape − 0.6)/0.4)`. It does not call `updateCoeffs()`, even though its `setDecay` (825) does.
- `SampleModel::setShape` (1945) never touches a `shape` field. It writes `start = clamp01(v)`, so on this model SHAPE sets the sample start point.
