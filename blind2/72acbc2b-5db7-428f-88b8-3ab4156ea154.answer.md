All 23 `setShape` overrides are in `src/modules/VXDrums/VXDrumVoices.hpp`. Each one is reached through `Voices::setShape` (line 2149), which calls `knobNatural(...)` (line 2153) to convert the knob position first.

**1. Recompute coefficients (call `updateCoeffs()`)**
- Without clamping: `Clap::setShape` :488. Its `updateCoeffs` uses `shape` as the clap spacing in ms (:476).
- With `clampd(v, 0.0, 1.0)` first: `SnareSweep` :1247, `SnareGate` :1341, `Clap909` :1454, `ClapLoFi` :1656, `ClapGate` :1756.

**2. Only store the value (`shape = v;`)**
- `Ping808` :346, `Snare909` :417, `SineKick` :653, `KickFm` :732, `Snare808` :922, `SnareLayered` :1009, `SnareRing` :1089.
- `KickFm`, `Snare808` and `SnareRing` clamp the stored value later, inside the per-sample code (:760, :961, :1104), not in the override.

**3. Clamp only, no recompute (`shape = clampd(v, 0.0, 1.0);`)**
- `Hat` :562, `Snare606` :1168, `ClapTrap` :1551.

**Overrides that do something else**
- `KickDist::setShape` :826–830 stores `shape`, then works out one value from it: `fold = fastMax(0.0, (shape - 0.6) / 0.4)`. It doesn't clamp and doesn't call `updateCoeffs()`.
- `SampleModel::setShape` :1945 doesn't touch `shape` at all. It writes `start = clamp01(v)`, so on this model SHAPE sets the sample start point.
