All 18 models are in `src/modules/VXDrums/VXDrumVoices.hpp`, and each one overrides `setShape` (the base declaration is `Model::setShape`, line 299).

**Recompute coefficients (call `updateCoeffs()`):**
- `Clap::setShape` :488. It stores `v` unclamped, then recomputes.
- `SnareSweep::setShape` :1247, `SnareGate::setShape` :1341, `Clap909::setShape` :1454, `ClapLoFi::setShape` :1656, `ClapGate::setShape` :1756. These clamp to 0..1 with `clampd` first, then recompute.

**Only store the value (`shape = v;`):**
- `Ping808` :346, `Snare909` :417, `SineKick` :653, `KickFm` :732, `Snare808` :922, `SnareLayered` :1009, `SnareRing` :1089.

**Clamp without recomputing (`shape = clampd(v, 0.0, 1.0);`):**
- `Hat` :562, `Snare606` :1168, `ClapTrap` :1551.

**Overrides that do something else:**
- `KickDist::setShape` :826–830 stores `shape`, then works out a second value inline: `fold = fastMax(0.0, (shape - 0.6) / 0.4)`. It doesn't clamp and doesn't call `updateCoeffs()`.
- `SampleModel::setShape` :1945 doesn't write to `shape` at all. It sets the sample start point, `start = clamp01(v)`, and recomputes nothing.

The value every override receives has already been mapped from the knob to its natural range by `Voices::setShape` (:2149–2153) through `knobNatural`.
