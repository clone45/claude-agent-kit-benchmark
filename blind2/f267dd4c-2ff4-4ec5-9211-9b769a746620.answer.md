All in `src/modules/PianoRoll/PianoRollEditorWidget.hpp` unless noted.

1. **Entry:** `onButton` (l.1624) handles a left-button press by calling `beginDrag(pos, mods)` (l.1889). Because `zoneAt` (l.1387) returns `ZONE_GRID`, `beginDrag` then calls `beginGridDrag(position, shift)` (l.2032).
2. **The order `beginGridDrag` checks things in:** it first works out `index = noteIndexAt(step, pitch)` (l.1409), which looks for the topmost note on the active track that contains the step, using the half-open span `[start, end)`. Then:
   - **(A)** If Shift is held, the click toggles that note in the selection, or starts a marquee if there is no note.
   - **(B)** `selectionBounds` (l.1455): if 2 or more notes are selected and the press is inside their bounding box, the drag moves the whole selection. Edges are never tested here, so a note inside a group cannot be resized.
   - **(C)** `edgeGrabAt(position, grab)` (l.1422): if it finds an edge, the drag is `DRAG_RESIZE`, and `drag_left_edge = grab.left_edge` chooses which edge.
   - **(D)** If the press is on a note body (`index >= 0`), `selectOnly` then `beginMove`.
   - **(E/F)** On empty space, the press clears the selection if there is one; otherwise it paints a new note.
   - `onHover` (l.1590–1601) shows the cursor using the same order: box, then edge, then body, then empty.
3. **Where the grab zone is computed:** in `edgeGrabAt`, l.1439: `zone = min(EDGE_GRAB_W, max(1, (x1-x0)/3))`. Here `x0`/`x1` are the note's left/right edges in pixels, from `xOfStep`. `EDGE_GRAB_W = 4` px is set in `PianoRollGeometry.hpp:127`. Notes 12 px or wider get the full ±4 px zone. Narrower notes get ±width/3, never less than 1 px, so a fixed zone can't cover the whole note and make it impossible to move.
4. **Right edge before left:** `edgeGrabAt` walks the notes topmost-first. For each note it tests the right edge first (l.1441, `|x - x1| <= zone`). Only after that does it test the left edge (l.1445).
5. **Why a short note's left edge can't be grabbed:** the left-edge test has an extra condition, `(x1 - x0) > EDGE_GRAB_MIN_NOTE_W`. That constant is `EDGE_GRAB_W * 2.5` = 10 px (`PianoRollGeometry.hpp:128`). The comment says the point is to avoid confusing a left-edge grab with a right-edge grab. So for a note 10 px wide or narrower, the left edge never registers. A press there either moves the note (inside it, step D) or counts as empty space or another note (outside it). Only the right edge stays resizable.
