Give Euclid an ACCENT output: a second trigger that fires on every Nth hit. This touches the engine, the module, the panel widget, and the user manual.

Engine (`src/modules/Euclid/EuclidEngine.hpp`, Rack-free, compiled standalone by `tests/euclid`):

- `Sequencer` gains a public `int accent_every`, default 0, clamped to 0..8 wherever it is read; 0 means off. It also gains a hit counter that counts the samples on which `struck` was reported since the last load or reset.
- `Sequencer::Out` gains `bool accent`. On a sample where `struck` is true the counter increments first; `accent` is then true when `accent_every` is at least 1 and the counter is a multiple of `accent_every`. On every other sample `accent` is false. So with `accent_every` 1 every hit is accented, and with 2 the second, fourth, sixth hit and so on.
- `load()` zeroes the counter. A reset zeroes the counter before counting that sample's own strike, so a reset that plays step 1 makes that strike hit number 1.
- Changing `accent_every` while running does not reset the counter. The existing six-argument `process` keeps its signature; nothing else in the engine changes.

Module (`src/modules/Euclid/Euclid.hpp`):

- Add `ACCENT_PARAM`, a snapping knob from 0 to 8 with default 0 labelled "Accent every", and `ACCENT_OUTPUT` labelled "Accent (10 V pulse on every Nth hit; 0 is off)".
- Each sample, set the engine's `accent_every` from the knob, and when the engine reports `accent`, start a pulse on `ACCENT_OUTPUT` of the same length as the TRIG pulse, using the same pulse mechanism TRIG uses.

Widget (`src/modules/Euclid/EuclidWidget.hpp`):

- Add a `Trimpot` for `ACCENT_PARAM` and a `VoxglitchOutputPort` for `ACCENT_OUTPUT`. The panel SVG has no anchors for them, so place them with explicit coordinates in free space on the 8 HP panel that does not overlap the existing controls (read the panel SVG under `res/` to see where those are). A small text label next to the knob is welcome but not required.

Manual (`docs/modules/euclid/user_manual.md`): describe the new knob in the Controls section and the new output where the outputs are described, in the manual's existing voice.

Add engine tests to `tests/euclid` covering off, every hit, every second hit, the reset rule, and the clamp. All existing tests must keep passing, and `bash scripts/vg_check.sh compile Euclid` must be clean.
