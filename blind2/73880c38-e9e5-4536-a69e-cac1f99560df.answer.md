All overrides are in `src/modules/VXDrums/VXDrumVoices.hpp` and are reached through `Voices::setShape` (line 2149). There are 18 models: 6 recompute, 7 only store, 3 clamp only, and 2 do something else.

**1. Recompute coefficients (6):**
- `Clap::setShape` (488) stores without clamping, then calls `updateCoeffs()`, which derives the burst `spacing` from shape (lines 476–478).
- `SnareSweep::setShape` (1247), `SnareGate::setShape` (1341), `Clap909::setShape` (1454), `ClapLoFi::setShape` (1656) and `ClapGate::setShape` (1756) clamp to 0..1, then call `updateCoeffs()`.

**2. Store only, `shape = v;` (7):**
- `Ping808` (346), `Snare909` (417), `SineKick` (653), `KickFm` (732), `Snare808` (922), `SnareLayered` (1009), `SnareRing` (1089).
- Four of these clamp later, when the value is used, instead of in the setter: `KickFm` (760), `Snare808` (961), `SnareRing` (1104, range 1..4) and `KickDist` (851, in group 4).

**3. Clamp to 0..1 without recomputing (3):**
- `Hat::setShape` (562), `Snare606::setShape` (1168), `ClapTrap::setShape` (1551).
- `ClapTrap` reads the stored value in `strike()` to randomize each hit's click gaps and levels (lines 1561–1563).

**4. Different from all three (2):**
- `KickDist::setShape` (826) stores shape without clamping and computes its derived `fold = max(0, (shape − 0.6)/0.4)` right there (line 829). It does not call `updateCoeffs()`, so it updates one derived value but isn't a full coefficient recompute.
- `SampleModel::setShape` (1945) has no `shape` field at all. It writes `start = clamp01(v)`, so SHAPE sets the sample's start position, and nothing is recomputed.
