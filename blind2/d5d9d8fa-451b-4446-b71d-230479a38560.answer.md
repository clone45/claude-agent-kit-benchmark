All `setShape` overrides are in `src/modules/VXDrums/VXDrumVoices.hpp`. Each one that recomputes calls an `updateCoeffs()` that does read `shape`.

- **Recompute coefficients:**
  - Without clamping: `Clap::setShape` (L488).
  - Clamp to 0..1, then recompute: `SnareSweep` (L1247), `SnareGate` (L1341), `Clap909` (L1454), `ClapLoFi` (L1656), `ClapGate` (L1756).
- **Only store the value (`shape = v`):** `Ping808` (L346), `Snare909` (L417), `SineKick` (L653), `KickFm` (L732), `Snare808` (L922), `SnareLayered` (L1009), `SnareRing` (L1089).
- **Clamp without recomputing (`shape = clampd(v, 0.0, 1.0)`):** `Hat` (L562), `Snare606` (L1168), `ClapTrap` (L1551).
- **Different from all three:**
  - `KickDist::setShape` (L826–830) stores `shape` unclamped, then works out one value from it, `fold = fastMax(0.0, (shape - 0.6) / 0.4)`. It doesn't call `updateCoeffs()`.
  - `SampleModel::setShape` (L1945) never writes `shape`. SHAPE becomes the sample start position, `start = clamp01(v)`, with no recompute.

Both callers convert the knob value with `knobNatural(...)` before calling `setShape`: `Voices::setShape` (L2149–2153) and the call at L2217.
