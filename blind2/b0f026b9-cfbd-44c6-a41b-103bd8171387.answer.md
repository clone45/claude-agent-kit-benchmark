All 18 models override `Model::setShape` (pure virtual, `src/modules/VXDrums/VXDrumVoices.hpp:299`), and SHAPE reaches them through `Voices::setShape` (2149–2153), which converts the knob position to a natural value with `knobNatural`. Every line below is in `VXDrumVoices.hpp`.

1. **Recompute coefficients (6):** each override calls `updateCoeffs()`, and each `updateCoeffs` does read `shape`.
   - Clap (488) stores without clamping; its `updateCoeffs` turns `shape` in ms into the burst `spacing` (472–478).
   - Clamp to 0..1 and then recompute: SnareSweep (1247, sweep time, 1234), SnareGate (1341, tail t60, 1320), Clap909 (1454, burst count and spacing, 1439), ClapLoFi (1656, `holdRate`, 1640), ClapGate (1756, tail t60, 1737).
2. **Store only, `shape = v;` (7):** Ping808 (346), Snare909 (417), SineKick (653), KickFm (732), Snare808 (922), SnareLayered (1009), SnareRing (1089).
   - These read `shape` live during `tick`.
   - KickFm (760), Snare808 (961) and SnareRing (1104, range 1..4) clamp it there instead of in the setter.
3. **Clamp to 0..1 without recomputing (3):** Hat (562, read in `tick` at 578), Snare606 (1168, read at 1201), ClapTrap (1551, read in `strike` at 1561–1563 for humanize).
4. **Different from all three:**
   - **KickDist (826–830):** stores the value without clamping and derives `fold = max(0, (shape-0.6)/0.4)` right there. `updateCoeffs` is not called; drive is clamped later in `tick` (851).
   - **SampleModel (1945):** has no `shape` member. It writes `start = clamp01(v)`, the playback start point, which `strike` uses through `data->startFrame(start)` (1955).
   - **Ping808 (346):** a store-only model, but SHAPE means two things. It is punch for the bass drum with drive fixed at 0.25, and drive for the rimshot with no punch (362–363).
